###   Project 2 — Sales Data Analysis System

# Overview

A NumPy-based sales analysis project that generates synthetic sales data for four products across seven days and performs revenue analysis.

# Concepts Practiced

- NumPy array creation
- "np.column_stack()"
- Broadcasting
- Aggregation using "axis=0" and "axis=1"
- "np.argmax()" and "np.argmin()"
- Boolean indexing and filtering
- Sorting with "np.sort()"
- Random number generation and reproducibility
- Revenue comparison
- Percentage calculations
- Python conditional statements and loops

# Features

1. Generates a sales dataset for four products over seven days.
2. Calculates daily and product-wise revenue.
3. Identifies the highest and lowest revenue days.
4. Filters days with revenue greater than 20,000.
5. Sorts daily revenue in descending order.
6. Compares two sales datasets.
7. Identifies the best-selling product.
8. Calculates each product's percentage contribution to total revenue.

# Technologies

- Python
- NumPy
