# 3. Creating NumPy Arrays

- "np.array()" — Creates arrays.
- "np.zeros()" — Creates arrays filled with zeros.
- "np.ones()" — Creates arrays filled with ones.
- "np.arange()" — Generates values using a step size.
- "np.linspace()" — Generates evenly spaced values.
- "np.full()" — Creates arrays filled with a specified value.

# 4. NumPy Array Properties

Property| Purpose
"shape"| Returns array dimensions
"ndim"| Returns number of dimensions
"size"| Returns total elements
"dtype"| Returns element data type
