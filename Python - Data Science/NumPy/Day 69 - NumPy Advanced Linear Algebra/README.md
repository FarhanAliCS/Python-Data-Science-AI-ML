###   Day 69 — NumPy Advanced Linear Algebra

# Overview

Day 69 focuses on advanced Linear Algebra operations using NumPy. These operations are important in Machine Learning, Deep Learning, dimensionality reduction, and mathematical computations.

# Topics Covered

1. Identity Matrix

- Created identity matrices using "np.eye()".
- Understood the identity property of matrix multiplication.

2. Matrix Transpose

- Used ".T".
- Used ".transpose()".
- Understood rows-to-columns and columns-to-rows conversion.

3. Determinant

- Calculated determinants using "np.linalg.det()".
- Learned the 2×2 determinant formula.
- Understood singular and non-singular matrices.

4. Matrix Inverse

- Calculated inverses using "np.linalg.inv()".
- Learned the relationship between a matrix and its inverse.
- Verified the identity matrix using "np.allclose()".

5. Matrix Rank

- Calculated matrix rank using "np.linalg.matrix_rank()".
- Understood linearly independent and dependent rows.
- Learned about redundant information in matrices.

6. Eigenvalues and Eigenvectors

- Used "np.linalg.eig()".
- Learned the relationship "Av = λv".
- Understood eigenvector directions and eigenvalue scaling.
- Explored their application in PCA.

7. Solving Linear Equations

- Learned matrix representation "AX = B".
- Used "np.linalg.solve(A, B)".
- Understood how NumPy finds unknown variables in linear equations.

# Important NumPy Functions

# Function| Purpose
"np.eye()"| Create identity matrix
"np.transpose()"| Transpose matrix
"np.linalg.det()"| Calculate determinant
"np.linalg.inv()"| Calculate inverse
"np.linalg.matrix_rank()"| Calculate matrix rank
"np.linalg.eig()"| Calculate eigenvalues and eigenvectors
"np.linalg.solve()"| Solve linear equations
"np.allclose()"| Compare arrays approximately

# Learning Outcomes

- Perform advanced matrix operations.
- Understand determinants, inverses, and matrix rank.
- Understand the fundamentals of eigenvalues and eigenvectors.
- Solve systems of linear equations using NumPy.
- Build a stronger mathematical foundation for AI and Machine Learning.
